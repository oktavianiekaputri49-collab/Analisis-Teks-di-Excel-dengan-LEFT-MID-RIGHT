📊 Analisis Data Teks Karyawan dengan Excel
Deskripsi
Proyek ini berfokus pada pengolahan data teks menggunakan Microsoft Excel. Data karyawan seperti nama, divisi, tahun lahir, dan NIK diolah menjadi format yang lebih terstruktur menggunakan fungsi teks.

Tools & Fungsi yang Digunakan
- Microsoft Excel
- Fungsi teks:
  - CONCATENATE (menggabungkan teks)
  - LEN (menghitung panjang teks)
  - LEFT (mengambil karakter dari kiri)
  - MID (mengambil karakter di tengah)
  - RIGHT (mengambil karakter dari kanan)

Hasil Analisis
- Data karyawan berhasil digabung menjadi ID terstruktur
- NIK dapat dipisahkan berdasarkan bagian tertentu
- Informasi teks dapat diolah sesuai kebutuhan analisis

Tujuan Proyek
Proyek ini dibuat untuk:
- Memahami penggunaan fungsi teks di Excel
- Melatih pengolahan data berbasis string
- Mengubah data mentah menjadi format yang lebih rapi dan informatif

Insight
Fungsi teks di Excel sangat berguna untuk mengolah data tidak terstruktur seperti nama atau NIK, sehingga data lebih mudah dianalisis dan digunakan kembali.

Penutup
Proyek ini merupakan latihan dasar pengolahan data teks menggunakan Excel dan dapat dikembangkan lebih lanjut dengan data yang lebih kompleks.
